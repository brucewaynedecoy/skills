# Skills

A collection of custom agent skills for extending Codex with focused, repeatable workflows.

## Included skills

| Skill | What it does |
| --- | --- |
| [Automation Dispatcher](automation-dispatcher/README.md) | Creates and operates durable collections of scheduled agent workflows through a task-bound dispatcher, a Python CLI, and an external SQLite registry. |
| [Bear](bear/SKILL.md) | Operates the macOS Bear app through the official `bearcli` command-line tool, including searching, reading, editing, organizing, and exporting notes. |
| [Bro](bro/SKILL.md) | Gets the model to restate its last message in plain and simple english. (User invoked) |
| [Kindex Ingest](kindex-ingest/SKILL.md) | Extracts people, projects, decisions, questions, and action items from notes, transcripts, and documents, then writes them into a Kindex knowledge graph as typed nodes and edges through `kin import`. |
